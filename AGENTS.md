# Lumma Website Development Guide

## Product architecture

Lumma Creative Studio is the organisation and creative studio. Aya is the central educational and creative universe. Aya The Little Muslim, Aya Fun Lingua, Aya Books, and future Aya initiatives are connected parts of that ecosystem and must not be presented as unrelated companies.

## Technical architecture

The public website is a static Astro project intended for GitHub Pages. Keep the project compatible with static generation and free hosting. Do not introduce a database, paid CMS, server dependency, proprietary hosting requirement, or unnecessary framework without explicit approval.

## Content architecture

Products, projects, and resources should become data-driven as the catalogue grows. Do not hard-code individual products into shared layout components. Prefer reusable components and structured content.

## Confidentiality

Never add confidential business-plan material to the public repository. This includes financial projections, costs, market calculations, internal strategy, private personal contact details, unpublished commercial plans, credentials, API keys, or private documents.

## Design

Preserve Lumma's existing warm, family-oriented visual direction while allowing studio, product, and collaboration pages to feel more professional and mature. Aya pages may be more playful, but the site should remain consistent as one ecosystem.

## Quality requirements

All changes should preserve responsive behaviour, semantic HTML, keyboard accessibility, visible focus states, and compatibility with GitHub Pages.
